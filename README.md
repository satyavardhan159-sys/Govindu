# GoVindu Catering Website

A modern, responsive food catering website built with React.js and Vite.

## Features

- **Homepage**: Hero section with image slider showcasing catered food
- **Navigation**: Responsive navigation bar with smooth scrolling
- **Services**: Display of catering services (weddings, corporate events, private parties)
- **Gallery**: Image gallery with lightbox functionality
- **Menu**: Categorized menu items with pricing and images
- **Pricing**: Three pricing packages (Silver, Gold, Platinum)
- **Testimonials**: Customer testimonials in a carousel format
- **Contact**: Contact form with Google Maps integration placeholder
- **Footer**: Quick links, contact information, and newsletter signup

## Technology Stack

- **Frontend**: React.js with Functional Components and Hooks
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Image Carousel**: Swiper.js

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

### Lint Code

```bash
npm run lint
```
